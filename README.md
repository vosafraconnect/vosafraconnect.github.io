# VOSAFRA CONNECT

Site da VOSAFRA CONNECT: serviços agrícolas sob demanda no Espírito Santo, com piloto em Santa Teresa.
Pulverização com drone, mapeamento, apoio agronômico, limpeza de placas solares e Rota Safra (rotas coletivas).

## Estrutura
- `index.html`: página principal
- `css/style.css`: visual (cores e fontes da marca)
- `js/main.js`: interações, formulário e WhatsApp (número em `WA_NUMBER`)
- `js/scenes3d.js`: cenas 3D (Three.js)
- `js/films.js`: animações 2D de reserva para aparelhos sem 3D
- `img/`: símbolo e vídeos
